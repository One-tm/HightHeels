# Heels Please

Статический сайт на Astro. Подбор формирует ссылки на официальные каталоги и сообщение для Telegram. Наличие и итоговая стоимость уточняются перед заказом.

## Проверка и сборка

Нужен Node.js 22.6 или новее для тестов TypeScript.

```sh
npm ci
npm run check
npm test
npm run build
```

Готовые страницы находятся в `dist/`. Если локальный сервер Astro не запускается из каталога с `#` в пути, готовую сборку можно проверить через `python -m http.server 4322 --bind 127.0.0.1 --directory dist`.

## Контент и подбор

- `src/data/catalog.ts` — параметры, подписи высоты, маршруты официальных каталогов и сборка запроса. Тройки: 8″, четвёрки: 9″, пятёрки: 10″. Высота платформы зависит от модели.
- `src/data/community.ts` — отзывы и снимок числа участников. Проверено в Telegram Desktop 3 октября 2026: 3 790 участников; на сайте указано «Более 3 700» с датой проверки. Счётчик не обновляется автоматически.
- Исходные отзывы: [Дарья](https://t.me/pleaserrussia/30959), [Настя](https://t.me/pleaserrussia/30754), [Юлия](https://t.me/pleaserrussia/30121). Текст сохранён; показаны короткие имена, без личных контактов.

Внешние фильтры Pleaser и Hella проверены по официальным страницам. Они могут измениться на стороне брендов. Размер, посадка и неоднозначные параметры передаются в текст запроса; возле каждой ссылки показаны применённые и оставшиеся параметры.

Длина стопы, город, модель и комментарий остаются в текущей странице: не сохраняются в URL или постоянное хранилище. Скопированный запрос пользователь самостоятельно отправляет в группу.

## Аналитика

Счётчик Яндекс Метрики: `113264514`. Для отчётов создайте в его настройках цели типа «JavaScript-событие» с идентификаторами:

- `picker_entry` — переход к подбору;
- `picker_open` — открытие подбора;
- `picker_change` — изменение параметров;
- `catalog_open` — переход в каталог бренда;
- `request_copy` — успешное копирование запроса.

События передаются без значений полей. Настройки целей в кабинете Метрики код сайта не создаёт.
